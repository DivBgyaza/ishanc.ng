# Ishanc.ng Portfolio

Portfolio website for Aisha Bashir Mashi, founder of Ishanc.ng.

## Add Aisha's portrait

Place the selected portrait at `dist/assets/aisha-bashir.jpg`. The website includes a branded fallback until the image is added.

## Preview

Open `dist/index.html` in a browser or serve the `dist` directory with any static server.
